# Local Food Wastage Management System

## Project Overview
The Local Food Wastage Management System is designed to reduce food wastage by connecting food providers with receivers through a centralized platform.

## Technologies Used
- Python
- SQLite
- SQL
- Streamlit
- Pandas

## Features
- Food Listings Management
- SQL-Based Analysis
- Provider Contact Information
- CRUD Operations
- Filtering by City, Food Type, and Meal Type

## Datasets
- providers_data.csv
- receivers_data.csv
- food_listings_data.csv
- claims_data.csv

## How to Run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run the Streamlit application:

```bash
streamlit run app.py
```
